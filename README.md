# 本機報價單管理系統

以 React + Tailwind CSS（shadcn 風格元件）製作的簡易報價單管理工具。

## 啟動

請先安裝 Node.js 20 以上版本，於專案資料夾執行：

```powershell
npm.cmd install
npm.cmd run dev
```

執行後會自動開啟 `http://127.0.0.1:5173`。首次儲存時，請選擇要建立資料檔的位置；系統會將報價、類別與客戶資料一起存成 `quotation-data.json`，之後可用「開啟資料檔」載入或直接更新同一檔案。

## 功能

- 供應商、客戶資料與可增刪的報價品項
- 小計、折扣、稅金、訂金與尾款的即時計算
- 報價歷史清單、客戶與類別資料都儲存在使用者選擇的本機 JSON 檔
- 適合 A4 的列印版面
